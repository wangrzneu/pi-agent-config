# 自动生成、预览审批、自动执行并持久化临时 Workflow

Workflow 定义为一次任务的临时结构化执行计划：系统根据用户任务自动识别并生成，先展示完整预览，用户整体批准后才允许自动修改文件并连续执行；同时持久化计划和执行状态，以便跨 Pi 重启恢复。选择这一形态是为了处理需要依赖关系和验证的多步骤任务；安全上仍由现有 sandbox 和 tool interceptor 控制权限，workflow 不得自行提升能力，失败只进行有限重试并在耗尽后暂停。

## Considered Options

- **显式命令 + 每步确认**：安全边界更清晰，但交互成本高；本方案改为自动生成、整体预览和整体批准。
- **只生成自然语言计划**：无法可靠恢复，也无法表达步骤状态、验证条件和重试预算。
- **生成并执行任意脚本**：可执行性强，但难以复用现有工具授权和 sandbox 安全边界，因此拒绝；结构化 workflow 必须先经过整体批准。
